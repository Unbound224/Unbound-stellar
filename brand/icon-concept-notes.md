Two distinct interlocking forms surround a shared opening, with a detached square representing value no longer trapped in one system.

Approved by the project owner on 2026-11-02 based on the final three-panel flat-logo design. Reconstructed into actual vector paths from the approved composition; not a bitmap masquerading as SVG.

Use `mark.svg` for transparent layouts, `icon.svg` for light/dark GitHub README rendering, and `org-avatar.png` for GitHub org identity. All branding uses flat fills only.
